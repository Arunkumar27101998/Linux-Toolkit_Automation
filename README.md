# Linux Automation Toolkit

## Project Description
Automated Linux system administration
using Bash scripting.

## Features
1. System monitoring
2. Disk cleanup
3. Backup automation
4. Service monitoring
5. User auditing
6. Process monitoring
7. Cron scheduling

## Technologies
- Ubuntu Linux
- Bash scripting
- Cron
- Linux system commands

## Execution

chmod +x main.sh

./main.sh

## Logs
All automation logs are stored
inside the logs directory.

## Backups
Compressed backups are stored
inside the backups directory.
